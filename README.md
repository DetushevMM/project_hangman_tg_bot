🎮 Hangman Telegram Bot

«Hangman Telegram Bot — Telegram-бот для игры в классическую «Виселицу», написанный на C++20 с использованием библиотеки tgbot-cpp.»

Проект демонстрирует разработку модульного backend-приложения с использованием современных возможностей языка C++, файлового хранения состояния и интеграции с Telegram Bot API.

---

📖 Описание проекта

Проект представляет собой Telegram-бота, позволяющего играть в «Виселицу» непосредственно в чате Telegram.

Каждый пользователь (или чат) имеет собственную независимую игровую сессию, которая автоматически сохраняется после каждого хода и восстанавливается после перезапуска программы.

Основные задачи проекта:

- реализация игровой логики;
- работа со словарём слов;
- интеграция с Telegram Bot API;
- сохранение состояния игры;
- демонстрация современной архитектуры приложения на C++20.

📄 Необходимые файлы

token.txt

Файл содержит токен Telegram-бота.

Пример:

123456789:AAxxxxxxxxxxxxxxxxxxxxxxxxxxxx

---

words.txt

Словарь слов.

Пример:

apple
banana
computer
developer
telegram
algorithm

Используются только слова, состоящие из букв.

---

state.txt
- Файл создаётся автоматически.
- Используется для хранения игровых сессий пользователей.

🎮 Команды

Команда| Описание
"/start"| Приветствие
"/help"| Справка
"/newgame"| Начать новую игру

После начала игры пользователь отправляет по одной букве в сообщении.

🧩 Модули проекта

HangmanGame

Реализует игровую логику.

Отвечает за:

- хранение загаданного слова;
- открытие букв;
- подсчёт ошибок;
- определение победы;
- определение поражения.

---

WordGenerator

Работает со словарём.

Выполняет:

- загрузку слов из файла;
- проверку корректности слов;
- перевод в нижний регистр;
- случайный выбор слова.

---

HangmanTgBot

Отвечает за взаимодействие с Telegram.

Выполняет:

- обработку команд;
- обработку сообщений;
- управление игровыми сессиями;
- сохранение состояния;
- загрузку состояния;
- отправку ответов пользователю.

---

💾 Сохранение состояния

После каждого действия пользователя автоматически сохраняются:
- идентификатор чата;
- загаданное слово;
- текущая маска;
- количество ошибок.

После повторного запуска приложения все игры продолжаются с того же места.

---

🎲 Генерация случайных чисел

Используются современные средства стандартной библиотеки C++:

- "std::mt19937_64"
- "std::uniform_int_distribution"

Использование "rand()" и "srand()" отсутствует.

---

🛡 Обработка ошибок

Программа корректно обрабатывает:

- отсутствие словаря;
- пустой словарь;
- ошибки открытия файлов;
- повреждённый файл состояния;
- ошибки Telegram API;
- стандартные исключения C++.
